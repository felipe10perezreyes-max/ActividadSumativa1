# Actividad Sumativa 1 - Programación Orientada a Objetos (Semana 3)

## Descripción del Proyecto
Aplicación desarrollada en Java bajo un paradigma de Programación Orientada a Objetos (POO), implementando encapsulamiento estricto, composición de clases, arquitectura modular por paquetes y ejecución mediante una clase principal.

## Estructura de Paquetes
* **com.actividad.model**: Contiene las clases del dominio (`Categoria` y `Producto`) con atributos privados, constructores, `getters/setters` y el método `toString()`.
* **com.actividad.app**: Contiene la clase principal (`Main`) encargada de la instanciación de objetos y validación funcional.
